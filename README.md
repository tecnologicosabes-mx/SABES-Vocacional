# SABES Vocacional · App Unificada

Versión con presentación institucional y logotipo SABES integrado en la interfaz y en la hoja individual de resultados.

## Incluye
- Una sola aplicación para Alumno, Docente y Administración.
- Hoja única de resultados por alumno.
- Barras de resultados por área.
- TOP 3.
- Acumulado de evaluaciones en el navegador (modo demo).
- Exportación a Excel compatible (.xls), CSV y JSON.
- Preparación para conexión con Supabase para almacenamiento en línea.
- Logotipo SABES local (`SABES_logo.svg`) en encabezado y reporte.

## Importante
La aplicación usa el archivo oficial `SABES.svg` alojado por el portal institucional de SABES (`https://portal.sabes.edu.mx/PagosenLinea/svg/SABES.svg`). Si no hay conexión al portal, conserva `SABES_logo.svg` como respaldo visual local. Para uso institucional definitivo, se recomienda conservar el archivo maestro/vectorial oficial proporcionado por SABES.

El sitio oficial de SABES muestra el uso institucional del logotipo SABES. Fuente consultada: https://portal.sabes.edu.mx/AdmisionesBachillerato/Help.aspx?id=1
